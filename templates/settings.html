Email Setup

Gmail SMTP (Free)

Customers receive booking confirmations automatically

1. Enable 2-Factor Auth on your Gmail account

2. Go to Google App Passwords

3. Create an app password for "Mail"

4. Set these env vars on Render:

MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password

AI Agent Calls (Optional)

Twilio Phone Calls

AI calls customers to confirm or notify about changes

Free accounts work with demo mode (logged to console). For real phone calls:

1. Sign up at twilio.com (free trial includes $15 credit)

2. Buy a phone number ($1/mo)

3. Set these env vars on Render:

TWILIO_ACCOUNT_SID=your-sid
TWILIO_AUTH_TOKEN=your-token
TWILIO_PHONE_NUMBER=+1234567890
